# Talkin LE License Server

Zero-dependency Node.js license server (sirf Node.js chahiye — koi npm install nahi).

## Deploy (Render.com)
- Build Command: (blank ya `npm install`)
- Start Command: `npm start`
- Env Var: `ADMIN_SECRET` = apna lamba sa secret

Har 5 min `https://<app>.onrender.com/v1/sys/status` ping karo (cron-job.org) taaki free instance soye nahi.
